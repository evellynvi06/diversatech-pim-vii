# diversatech-pim-vii
DiversaTech — Projeto Integrado Multidisciplinar VII (PIM VII) da UNIP. Plataforma corporativa de gestão da diversidade e inclusão, desenvolvida com ASP.NET Core, C#, APIs REST, Entity Framework Core e Flutter, integrando aplicações web e mobile para treinamento corporativo, equidade étnico-racial e gestão de indicadores.
